# 经典街机八线老虎机 - 女王蜂 (QUEEN BEE / SUBSINO)

本项目高度还原了 2000 年左右风靡各大街机厅的 **Subsino 原版经典 8-LINER 街机游戏《女王蜂》(Queen Bee)**。

---

## 🎮 游戏特色与机台机制还原 (100% 对应原厂机台参数)

1. **经典 3x3 九宫格与 8 条激活线 (8-LINER)**：
   - 3条水平横线 (Line 1 ~ 3)
   - 3条垂直竖线 (Line 4 ~ 6)
   - 2条交叉大斜线 (Line 7 ~ 8)
   - 机台四周设有原版 **红色押注分徽章**（每线最高可押 30 分，全满押为 240 分）。
2. **完全复刻的原厂赔率总表 (PAYTABLE)**：
   - **全盘特别大奖 (ALL AWARDS - 9格全满)**：
     - 👑 **ALL 皇冠 (全盘9个)**：**X1000** 顶级神奖
     - 💠 **ALL 浅蓝花**：**X500**
     - 🌸 **ALL 粉红花** / 🐞 **ALL 绿金龟**：**X400**
     - 🌺 **ALL 金黄花** / 🦗 **ALL 绿蚱蜢**：**X300**
     - 🐦 **ALL 小粉鸟**：**X200**
     - 🕷️ **ALL 蜘蛛**：**X100**
     - 🦋 **ALL 蜻蜓**：**X50**
     - 💐 **ALL ANY 花朵** (全盘任意花朵混合)：**X50**
     - 🦗 **ALL INSECT 昆虫** (全盘任意昆虫混合)：**X15**
   - **散牌皇冠奖 (SCATTER CROWNS - 盘面任意位置出现数量)**：
     - **8 X 👑 皇冠**：**X400**
     - **7 X 👑 皇冠**：**X200**
     - **6 X 👑 皇冠**：**X100**
     - **5 X 👑 皇冠**：**X50**
     - **4 X 👑 皇冠**：**X20**
     - **3 X 👑 皇冠**：**X5**
     - **2 X 👑 皇冠**：**X2**
   - **单线 3 连匹配奖 (按单线押注计算)**：
     - 👑 皇冠: x100 | 💠 浅蓝花: x50 | 🌸 粉红花: x40 | 🐞 绿金龟: x30 | 🌺 金黄花: x20 | 🦗 绿蚱蜢: x15 | 🐦 小粉鸟: x10 | 🕷️ 蜘蛛: x8 | 🦋 蜻蜓: x5
3. **百搭女王蜂 (QUEEN BEE WILD)**：
   - 女王蜂图标为万能百搭符号，替换任意图案组成连线与大满贯，更支持 **x2 翻倍乘数**！
4. **比倍猜大小 (DOUBLE-UP)**：
   - 得分后可选择直接收分（TAKE SCORE）或进入比倍。
   - 🎲 经典 1~6（小）、8~13（大）猜点数翻倍，更设有点数 7 的 6 倍超高倍率！
5. **原汁原味街机音效**：
   - 基于 HTML5 Web Audio API 纯原生合成，复刻经典投币声、滚轮刹车声、彩灯连线声与大满贯庆祝声。

## 🕹️ 键盘操作快捷键
- **空格键 (Space)**：开始旋转 / 快速收分
- **C 键**：投币 (Coin +100)
- **B 键**：增加押注 (Bet Line +8)
- **M 键**：全满押 (Max Bet 240)
- **D 键**：进入猜大小 (Double Up)
